Valider une base d'architecture exploitable pour un logiciel Windows de gestion d'un magasin d'optique : **Tauri + React** en client, **API ASP.NET Core** centrale, **PostgreSQL seul SGBD**, installation serveur ou poste, exploitation monoposte/multiposte. Ne pas coder le logiciel.

- Définir les critères de GO de phase 01, faire un audit **de l'environnement Windows du futur projet** si celui-ci est fourni/autorisé.
- Classer le backlog 153 vues + 23 compléments en `DEFERRED`, avec exceptions documentées pour les exigences techniques critiques.
- Écrire les documents de cadrage hors du dépôt applicatif, puis les remettre au propriétaire.

## OUT (interdit)

- Consulter, cloner ou analyser l'ancien dépôt MMV ; réutiliser anciens modèles, règles, données ou Git.
- Créer le nouveau projet Tauri/.NET, une DB, une API, un prototype, des migrations, une branche ou des commits ; installer des outils sans nouveau GO.
